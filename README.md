# AwesomeFlows plugin

Connects your agent to the AwesomeFlows ecommerce UX flows library (https://awesomeflows.com) through its remote MCP server at `https://awesomeflows.com/api/mcp`.

## Setup
Install the plugin, then sign in with your AwesomeFlows account when prompted (OAuth; no API key needed).

## Tools
- `search_ecom_patterns` – search patterns across the library (requires an AwesomeFlows Pro subscription; free accounts receive an upgrade message)
- `get_flow` – fetch one flow and its screens
- `list_library` – browse the library
- `list_collections` / `get_collection` – browse curated collections

## Skill
`skills/awesomeflows-ux-research` – guidance for researching ecommerce UX with these tools.
