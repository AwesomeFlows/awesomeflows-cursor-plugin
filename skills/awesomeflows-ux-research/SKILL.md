# Researching ecommerce UX with AwesomeFlows

1. Start broad: `search_ecom_patterns` with the pattern name (e.g. "sticky add to cart", "cart drawer"). If it returns an upgrade message, tell the user search needs AwesomeFlows Pro and fall back to `list_library` / `list_collections`.
2. Open the most relevant results with `get_flow` to see the actual screens in order.
3. Use `list_collections` / `get_collection` for curated sets on a theme.
4. Cite the flows you used, and compare at least 2-3 real examples before recommending a pattern. Prefer mobile examples for mobile-first patterns.
5. Don't invent examples; only describe what the tools return.
